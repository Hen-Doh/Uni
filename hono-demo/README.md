# Hono Beispiel
## Installieren
To install dependencies:
```sh
bun install
```

## Starten
To run:
```sh
bun run dev
```

open http://localhost:3000 oder http://localhost:3000

## Ausprobieren mit Bruno
Über den Browser lassen sich nur GET-Anfragen leicht testen. Teste mit Bruno. Es gibt 2 Beispielanfragen, wenn du den Ordner `bruno/` mit [Bruno](https://www.usebruno.com/) öffnest.
